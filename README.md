# Telegram-магазин цифровых товаров — Bothost

## Самое главное

Откройте только файл:

`bot.py`

В самом начале файла находится большой блок:

```python
# ВАШ TELEGRAM ID
ADMIN_ID = 123456789
```

Замените `123456789` на свой Telegram ID.

**Токен бота вставлять в код не нужно.** Bothost передаёт токен через переменную окружения автоматически.

После этого запускайте:

```bash
python bot.py
```

Остальная логика магазина уже находится ниже в `bot.py`.
